# Projet de développement 
 
**Nom :** Roux Loïc, Léo Del Duca, Jason Roger
 
**Sujet :** Block Blast

**But du jeu :** Le Jeu  est un jeu 1 joueur. IL y a une grille de 8 pars 8. Nous pouvons y place des formes géométriques sans les tourner . 2 formes ne peuvent des superposer. Le but est de ne pas être bloqué .Lorsqu'une ligne est terminée elle se supprime ( ou colonne ) .

## Tâches
 
- Afficher le quadrillage
- Faire apparaître des tuiles
- Pouvoir supprimer des lignes
